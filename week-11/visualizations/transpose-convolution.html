Forward Convolution vs Transposed Convolution

Forward Convolution

4×4 → 3×3
Downsampling: extracts local features
y = W · x
Weight matrix W is (9×16), input is (16×1)

Transposed Convolution

3×3 → 4×4
Upsampling: distributes values back
x̃ = WT · y
WT is (16×9), input is (9×1)
Key insight: WT distributes output back in the same proportions as W collected it
Perfect reconstruction is impossible — information is irretrievably lost during forward convolution. The forward weight matrix is non-square and non-invertible.
